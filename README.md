# BRD Agentic Vision

This public repository contains the hackathon execution plan for using pen video to track Angus cattle, label behaviour, and explore assumption-based bovine respiratory disease (BRD) risk. The plan was drafted in Claude Code and reviewed by Codex.

| Start here | What it covers |
|---|---|
| [Plan index](plan/README.md) | Milestones, task board, and reading order |
| [Codex review](plan/CODEX_REVIEW.md) | Corrections, remaining blockers, and acceptance checks |
| [Team split](plan/07_team_split.md) | Three lanes and their handoffs |
| [Contracts](plan/02_contracts.md) | Data formats, schemas, and module interfaces |
| [Task cards](plan/tasks/) | T00–T33 with embedded acceptance tests, human tasks, and full-data runbooks |

The published snapshot contains the plan and review. The pipeline and its full acceptance suite remain unrun. The event videos, private fixtures, derived media, and credentials stay outside this repository.

The cards use example recording dates and paths. Real-data verification requires the private fixture manifest and original locked-test values, along with the authorized local data. The review describes the original plan’s execution risks and links to the corresponding sections in this public version.
